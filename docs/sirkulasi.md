## 1. Peran & Fungsi Divisi Sirkulasi

Divisi Sirkulasi adalah **tulang punggung distribusi fisik** surat kabar. Fungsinya:

> "Memastikan koran yang sudah dicetak di percetakan sampai ke tangan pembaca pada waktu yang tepat — melalui jaringan agen, sub-agen, loper, kios, dan pelanggan langganan — serta mengelola seluruh administrasi keuangan penjualannya."

Divisi ini berada di bawah **Manajer Pemasaran / Manajer Usaha**, dan berkoordinasi langsung dengan:
- **Percetakan / Pracetak** → untuk data tiras (jumlah eksemplar cetak)
- **Keuangan / Kasir** → untuk rekonsiliasi penjualan dan pembayaran agen
- **Iklan** → untuk data halaman iklan yang mempengaruhi oplah (edisi tertentu)
- **Redaksi** → untuk konfirmasi edisi khusus / suplemen

## 2. Terminologi Wajib Dipahami

| Istilah | Definisi |
|---|---|
| **Oplah / Tiras** | Total eksemplar koran yang dicetak pada satu edisi |
| **Eksemplar** | Satuan 1 buah koran |
| **Agen Utama** | Mitra distribusi besar, menerima ribuan eksemplar/hari, bertanggung jawab wilayah tertentu |
| **Sub-Agen** | Di bawah agen utama, menerima ratusan eksemplar, melayani area lebih kecil |
| **Pengecer / Loper** | Tingkat paling bawah — kios pinggir jalan, atau loper door-to-door |
| **Retur** | Koran tidak terjual yang dikembalikan ke agen / perusahaan |
| **Nett Sales / Nett Eksemplar** | Oplah − Retur = koran yang benar-benar terjual |
| **Surat Jalan (SJ)** | Dokumen resmi pengiriman: jumlah eksemplar, tujuan, tanggal, driver |
| **Drop Point** | Titik serah terima koran ke agen (bisa gudang KP atau lokasi agen) |
| **Bundel** | Paket bundel koran yang diikat (biasanya 10 atau 25 eksemplar per ikat) |
| **Langganan** | Pelanggan tetap yang bayar di muka (bulanan/tahunan) dan dikirim ke alamat |
| **Harga Agen** | Harga jual KP ke agen (di bawah harga eceran, sudah termasuk komisi agen) |
| **Harga Eceran** | Harga jual koran di kios/eceran untuk pembeli umum |
| **Harga Langganan** | Harga paket berlangganan (biasanya lebih murah dari eceran) |
| **Komisi Agen** | Selisih harga eceran − harga agen = keuntungan agen |
| **Piutang Agen** | Hutang agen ke KP atas koran yang sudah dikirim tapi belum dibayar |
| **Rekening Koran Agen** | Buku besar mutasi transaksi per agen (kirim, retur, bayar) |
| **Edisi** | Nomor edisi + tanggal terbit koran |
| **Alokasi** | Jatah eksemplar yang ditetapkan untuk setiap agen per edisi |
| **Susut** | Koran rusak/hilang dalam proses distribusi (tidak bisa diretur, jadi beban biaya) |
| **SPS** | Serikat Perusahaan Pers — lembaga yang mengaudit tiras/oplah secara independen |

## 3. Struktur Jaringan Distribusi

```
PERCETAKAN / PRACETAK
        │ (koran selesai cetak ~01.00–03.00 WIB)
        ▼
GUDANG SIRKULASI KABAR PRIANGAN
        │ (serah terima + bundeling)
        │
        ├──► AGEN UTAMA KOTA A
        │         │
        │         ├──► Sub-Agen 1 ──► Loper / Kios
        │         ├──► Sub-Agen 2 ──► Loper / Kios
        │         └──► Loper Langsung ──► Pembaca Eceran
        │
        ├──► AGEN UTAMA KOTA B
        │         └──► ...
        │
        ├──► AGEN UTAMA KOTA C (luar kota — via travel/kereta)
        │         └──► ...
        │
        └──► PELANGGAN LANGGANAN (dikirim langsung oleh loper KP)
                  ├──► Rumah Tangga / Perorangan
                  ├──► Kantor / Instansi / Pemda
                  └──► Hotel / Restoran / Sekolah
```

## 4. Alur Kerja Harian (Timeline Operasional)

### 🌙 SHIFT MALAM — Pra-Distribusi (22:00 – 02:00 WIB)

| Waktu | Kegiatan | PIC | Keterangan |
|---|---|---|---|
| 22:00 | Konfirmasi jumlah tiras dengan Pracetak/Percetakan | Manajer Sirkulasi | Berdasarkan alokasi agen + langganan + cadangan |
| 22:30 | Cetak Surat Jalan (SJ) per agen untuk esok hari | Admin Sirkulasi | SJ dicetak dari sistem berdasarkan alokasi |
| 23:00 | Siapkan bundel koran yang keluar dari mesin | Tim Gudang | Disortir per wilayah/agen |
| 01:00 | Serah terima koran dari percetakan ke gudang sirkulasi | Petugas Gudang | Dicatat jumlah eksemplar per bundel |
| 01:30 | Loading koran ke armada distribusi | Driver + Petugas | Sesuai SJ masing-masing |
| 02:00 | **BERANGKAT DISTRIBUSI** | Driver | Prioritas agen luar kota berangkat lebih awal |

### 🌅 SHIFT PAGI — Distribusi Aktif (02:00 – 07:00 WIB)

| Waktu | Kegiatan | PIC | Keterangan |
|---|---|---|---|
| 02:00 – 04:00 | Pengiriman ke agen-agen luar kota | Driver | Via travel, kereta, atau armada KP |
| 03:00 – 05:00 | Pengiriman ke agen-agen dalam kota | Driver Motor/Mobil | Serah terima langsung di drop point agen |
| 05:00 – 06:00 | Pengiriman langganan (home delivery) | Loper KP | Door-to-door ke pelanggan langganan |
| 06:00 | **TARGET: Koran sudah di kios & tangan pembaca** | — | Standar industri nasional |
| 06:00 – 08:00 | Konfirmasi penerimaan dari agen via telepon/WA | Admin Sirkulasi | Catat jika ada selisih jumlah |

### ☀️ SHIFT PAGI — Administrasi (08:00 – 12:00 WIB)

| Waktu | Kegiatan | PIC | Keterangan |
|---|---|---|---|
| 08:00 | Input konfirmasi penerimaan agen ke sistem | Admin Sirkulasi | Update status SJ: terkirim / ada selisih |
| 08:30 | Rekap agen yang belum konfirmasi | Admin Sirkulasi | Follow-up via telepon |
| 09:00 | Penagihan agen yang jatuh tempo (kunjungan / WA) | Kolektor Sirkulasi | Berdasarkan laporan piutang agen |
| 09:00 | Proses pembayaran langganan masuk | Admin Sirkulasi | Perpanjangan langganan, langganan baru |

### 🌤️ SHIFT SIANG — Retur & Rekonsiliasi (12:00 – 17:00 WIB)

| Waktu | Kegiatan | PIC | Keterangan |
|---|---|---|---|
| 12:00 – 14:00 | **Agen setoran retur koran** (koran kemarin yang tidak terjual) | Agen / Sub-Agen | Koran hari sebelumnya direturn |
| 14:00 – 15:00 | Hitung & input retur per agen ke sistem | Admin Sirkulasi | Nett Sales = Kirim − Retur |
| 15:00 | Rekap nett sales hari ini per wilayah | Admin Sirkulasi | Dasar tagihan ke agen |
| 15:30 | Update piutang agen: Piutang baru = Nett Sales × Harga Agen | Sistem Otomatis | — |
| 16:00 | Laporan distribusi harian ke Manajer | Admin Sirkulasi | Kirim, retur, nett, piutang |
| 16:30 | Persiapan alokasi untuk edisi esok hari | Manajer Sirkulasi | Berdasarkan data historis & permintaan |

### 📦 MENU 3 — Manajemen Tiras & Alokasi

#### 3.1 Input Tiras Harian

**Fungsi:** Mencatat jumlah total eksemplar yang keluar dari percetakan untuk edisi tertentu.

| Field | Keterangan |
|---|---|
| Edisi (Tanggal + Nomor Edisi) | Identitas edisi koran |
| Jumlah Tiras Total | Total eksemplar dicetak |
| Jumlah untuk Distribusi | Tiras − Cadangan Gudang |
| Cadangan Gudang | Stok darurat / keperluan iklan bukti muat |
| Catatan Edisi | Misal: edisi khusus, suplemen, dsb |
| Input Oleh | User yang menginput |
| Waktu Input | Timestamp |

#### 3.2 Alokasi Per Agen

**Fungsi:** Menetapkan berapa eksemplar yang dikirim ke masing-masing agen untuk setiap edisi.

**Logika Alokasi:**
```
Total Tiras untuk Distribusi
= Alokasi Agen 1 + Alokasi Agen 2 + ... + Alokasi Agen N
+ Alokasi Langganan
+ Cadangan Internal
```

**Fitur:**
- **Copy dari alokasi kemarin** — untuk efisiensi (tinggal edit yang berubah)
- **Alokasi otomatis** berdasarkan default alokasi di master agen
- **Override manual** — agen bisa request tambah/kurang
- **Validasi**: Total alokasi tidak boleh melebihi tiras yang tersedia
- **Riwayat perubahan alokasi** (siapa yang ubah, kapan, dari berapa ke berapa)

| Field | Keterangan |
|---|---|
| Edisi | Link ke tiras harian |
| Agen | Link ke master agen |
| Alokasi Default | Dari master agen |
| Alokasi Hari Ini | Bisa berbeda dari default |
| Alasan Perubahan | Opsional (misal: permintaan agen, edisi khusus) |
| Status | Draft / Dikonfirmasi / Dikirim |

#### 3.3 Cetak Surat Jalan (SJ)

**Fungsi:** Generate dokumen resmi pengiriman untuk setiap agen / rute.

**Konten Surat Jalan:**

### 🔄 MENU 5 — Retur Koran

#### 5.1 Input Retur Harian

**Fungsi:** Mencatat koran tidak terjual yang dikembalikan oleh agen.

> **Aturan Standar Industri:**
> - Retur hanya bisa untuk edisi D-1 (kemarin)
> - Batas waktu retur: biasanya sampai pukul 14:00 WIB hari berikutnya
> - Koran yang tidak diretur setelah batas waktu = dianggap terjual (ditagihkan penuh)

| Field | Keterangan |
|---|---|
| Edisi yang Diretur | Tanggal edisi koran |
| Agen | Link ke master agen |
| Jumlah Dikirim | Dari data pengiriman (auto-fill) |
| Jumlah Retur | Input manual (dicek fisik) |
| Nett Sales | Otomatis: Kirim - Retur |
| Kondisi Retur | Layak arsip / Rusak / Untuk promosi |
| Tanggal Retur Diterima | Timestamp |
| Diterima Oleh | User yang input |
| Catatan | Keterangan khusus |

#### 5.2 Rekap Retur Per Agen

**Fungsi:** Laporan retur per agen per periode, untuk evaluasi kinerja agen dan penyesuaian alokasi.

**Metrik Penting:**
- **Persentase Retur Agen** = (Retur / Kirim) x 100%
  - < 10% → agen bagus, bisa tambah alokasi
  - 10 – 20% → normal
  - > 20% → evaluasi, kurangi alokasi
- **Tren retur** per bulan — grafik naik/turun

**Fungsi:** Rekap semua agen dalam satu hari: kirim, retur, nett, nilai tagihan.

#### 6.2 Pendaftaran Langganan Baru

**Fungsi:** Form pendaftaran pelanggan baru.

```
Pelanggan daftar (datang langsung / telepon / online)
```

### 📈 MENU 8 — Laporan

#### 8.1 Laporan Distribusi Harian
Isi: Rekap kirim, retur, nett per agen untuk 1 edisi/tanggal.

#### 8.2 Laporan Tiras Bulanan
Isi: Total tiras setiap hari dalam 1 bulan, tren naik/turun, rata-rata oplah.

> **Fungsi Strategis:** Data tiras ini yang dilaporkan ke SPS dan digunakan sebagai dasar penetapan tarif iklan — makin tinggi oplah → tarif iklan lebih mahal.

#### 8.3 Laporan Retur Per Agen
Isi: Persentase retur per agen dalam 1 periode → basis evaluasi dan penyesuaian alokasi.

#### 8.4 Laporan Nett Sales Bulanan
Isi: Total eksemplar terjual per bulan per wilayah — revenue dari penjualan koran.

#### 8.5 Laporan Piutang Agen
Isi: Rekap piutang semua agen, aging, overdue.

#### 8.6 Laporan Langganan
Isi:
- Total pelanggan aktif saat ini
- Pelanggan baru bulan ini
- Pelanggan expired/berhenti bulan ini
- Revenue dari langganan per bulan
- Daftar renewal yang akan jatuh tempo

#### 8.7 Laporan Kinerja Distribusi
Isi:
- On-time delivery rate (berapa % koran sampai sebelum jam 06:00)
- Selisih SJ vs aktual diterima agen
- Kasus koran hilang/rusak dalam distribusi

## 6. Alur Keuangan Sirkulasi

```
PENJUALAN KORAN
      │
      ├── Via Agen
      │     Agen terima koran → jual ke pembaca
      │     Agen bayar ke KP = Nett Sales × Harga Agen
      │     (bukan harga eceran — selisihnya = komisi agen)
      │
      └── Via Langganan
            Pelanggan bayar di muka ke KP
            KP kirim koran setiap hari sampai langganan habis

PENERIMAAN KAS
      → Kasir terima pembayaran dari agen (tunai / transfer)
      → Kasir terima pembayaran langganan (tunai / transfer)
      → Input ke sistem → Update piutang agen = berkurang

REKONSILIASI (bulanan)
      → Sirkulasi vs Kasir → cocokkan total penerimaan
      → Sirkulasi vs Keuangan → cocokkan piutang outstanding
```

## 7. Koordinasi Antar Divisi

| Divisi Terkait | Kebutuhan dari Sirkulasi | Yang Diberikan ke Sirkulasi |
|---|---|---|
| **Percetakan / Pracetak** | Data oplah aktual per edisi | Konfirmasi jumlah tiras yang dibutuhkan |
| **Kasir** | Penerimaan pembayaran agen & langganan | Daftar agen yang harus ditagih, jumlah tagihan |
| **Keuangan** | Rekonsiliasi piutang bulanan | Laporan piutang agen outstanding |
| **Iklan** | Bukti muat koran (untuk lampiran tagihan iklan) | Info edisi khusus / suplemen (pengaruhi alokasi) |
| **Redaksi** | — | Info edisi khusus / hari libur (koran terbit atau tidak) |

## 9. Daftar Pertanyaan untuk Wawancara Lanjutan

> Hal-hal berikut BELUM terkonfirmasi dari KP dan perlu ditanyakan saat observasi detail.

### Tentang Struktur Distribusi
- [ ] Berapa total agen aktif saat ini? Sebutkan nama wilayah coverage-nya
- [ ] Apakah ada agen luar kota? Kalau iya, cara kirimnya bagaimana? (armada sendiri / travel / kereta?)
- [ ] Apakah ada sub-agen dan loper? Atau langsung dari KP ke agen saja?
- [ ] Armada distribusi: berapa motor/mobil yang dimiliki KP?

### Tentang Tiras & Alokasi
- [ ] Berapa oplah/tiras harian rata-rata KP sekarang?
- [ ] Siapa yang memutuskan alokasi per agen? (Manajer Sirkulasi sendiri atau ada rapat?)
- [ ] Apakah alokasi agen sudah tetap atau berubah setiap hari?
- [ ] Saat ini proses alokasi masih manual (Excel) atau sudah ada sistem?

### Tentang Surat Jalan
- [ ] Apakah SJ saat ini masih manual/ditulis tangan atau sudah dicetak?
- [ ] Siapa yang tanda tangan SJ? (dari KP dan dari agen)
- [ ] Apakah ada kopi SJ yang disimpan? Berapa rangkap?

### Tentang Retur
- [ ] Jam berapa batas retur koran dari agen?
- [ ] Apakah semua agen boleh retur atau ada agen yang "konsinyasi penuh" (tidak boleh retur)?
- [ ] Koran retur yang kembali ke KP, apa yang dilakukan? (dibuang / diarsip / dijual murah?)
- [ ] Apakah ada batas maksimum retur per agen (misal: max retur 20% dari alokasi)?

### Tentang Langganan
- [ ] Berapa jumlah pelanggan langganan aktif sekarang?
- [ ] Siapa yang mengantar ke pelanggan langganan? (loper internal KP / disubkontrak ke agen?)
- [ ] Paket langganan apa saja yang tersedia? (bulanan, 3 bulan, tahunan?)
- [ ] Berapa tarif langganan saat ini?
- [ ] Apakah ada diskon untuk instansi / langganan jangka panjang?

### Tentang Pembayaran Agen
- [ ] Agen bayar ke KP berapa hari sekali? (harian / mingguan / bulanan?)
- [ ] Bagaimana cara agen bayar? (tunai datang ke kantor / transfer / diambil kolektor?)
- [ ] Apakah ada kredit limit per agen? Berapa limit-nya?
- [ ] Jika agen telat bayar / melebihi limit, apa yang dilakukan? (pengiriman distop? didenda?)

### Tentang Sistem Saat Ini
- [ ] Apakah divisi sirkulasi saat ini sudah menggunakan komputer / aplikasi?
- [ ] Jika iya, aplikasi apa yang dipakai? (Excel / software khusus?)
- [ ] Data apa saja yang sudah tercatat secara digital vs masih di buku/kertas?
- [ ] Siapa yang mengoperasikan sistem sehari-hari? (1 orang admin atau lebih?)
- [ ] Laporan apa yang rutin dicetak / dikirim ke atasan?
